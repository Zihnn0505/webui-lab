# W04 Learning Log

## 1. Project Brief Presentation

### 1.1 Problem Statement
In the project brief presentation, the main concern was whether the website had a realistic user group and whether the project scope could be completed within the semester.

### 1.2 Discussion and Resolution
During discussions with AI and the professor, two key issues were identified:

#### Problem 1: Who will use my website?
Because the project is a demonstration platform, there is no immediate real user base. As a result, the website does not yet have a real operational environment. To address this, I decided to design a feedback mechanism for the demo version so that the project can still be evaluated and improved based on user feedback.

#### Problem 2: Completing all functions within 12 weeks
The professor and AI both pointed out that the project could not realistically include every desired function within the time limit. To manage scope effectively, I decided to abandon payment gateway integration and simplify the data storage approach by using JSON files instead of a full database system.

## 2. Work Completed This Week
- Completed the homepage HTML structure and CSS styling.
- Separated the sidebar into an independent file and loaded it dynamically using JavaScript.

## 3. Reflection
This week’s discussion helped clarify the project’s realistic scope and practical constraints. I learned that a project should not only focus on adding more functions, but also prioritize feasibility, time management, and user value. By reducing complexity in payment integration and storage design, the project became more achievable while still maintaining a clear demonstration objective.
